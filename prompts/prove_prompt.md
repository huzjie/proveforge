# 证明提示词（Prove）

任务：为一个 prompt 生成可验证的证明，把输出绑定到已承诺的权重。

步骤：
1. 用承诺的模型做贪婪解码，记录每一步的执行轨迹（各层激活、logits、argmax token）。
2. 计算 Fiat-Shamir 挑战：seed = H(COMMITMENT || prompt || output || 轨迹摘要)。
3. 用挑战的伪随机采样决定打开哪些权重行。
4. 为每个被打开的行附上权重值 + Merkle 兄弟路径。

约束：
- 只打开被挑战命中的行，其余权重保持隐藏。
- 声称的输出 token 必须与轨迹的 argmax 一致（否则视为篡改）。
- 轨迹必须真实反映所用权重的计算（否则视为伪造）。
