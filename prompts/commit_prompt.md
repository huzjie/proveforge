# 承诺提示词（Commit）

任务：把一组模型权重量化后做 Merkle 承诺，只公开根哈希。

步骤：
1. 将浮点权重量化为 bits 位整数，模 2^bits。
2. 按 (layer, row, col) 顺序展平成叶子序列。
3. 叶子哈希 = H(0x00 || idx || value)；内部节点 = H(0x01 || left || right)。
4. 计算 Merkle 根，作为 COMMITMENT 公开。

约束：
- 只公开根哈希与架构（词表/层数/位宽），不公开任何权重数值。
- 根必须对权重的任何一位变化敏感（绑定性）。
- 用域分离（0x00/0x01）防止叶子与内部节点歧义。
